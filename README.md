# Calculadora de IMC em Python

Projeto desenvolvido em Python para calcular o Índice de Massa Corporal (IMC) e apresentar sua classificação para adultos de 19 a 59 anos.

## Funcionalidades

- Solicitação do nome e da idade do paciente.
- Entrada de peso e altura.
- Cálculo do IMC.
- Classificação do resultado.
- Exibição das informações com cores no terminal.
- Verificação da faixa etária permitida.

## Tecnologias e conceitos utilizados

- Python
- Estruturas condicionais (`if`, `elif` e `else`)
- Operadores matemáticos
- Entrada e saída de dados (`input` e `print`)
- F-strings
- Manipulação de strings (`strip`, `lower` e `capitalize`)
- Cores ANSI no terminal
- Módulo `time` (`sleep`)

## Objetivo

Praticar os conhecimentos de Python por meio de um projeto próprio, aplicando lógica de programação e estruturas condicionais.
